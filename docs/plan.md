# Xiaoyuan Memory Graph — Build Plan

## Scope

A new, standalone project for the Neo4j Relate Hackathon 2026. It turns the real local regression transcript of Xiaoyuan 14B (`ten_question_regression_full.json`, 10 cases / 31 turns) into a queryable Relate by Neo4j graph. Relate is the only storage and query layer. No hosted model and no fabricated benchmark score.

## Acceptance IDs

| ID | Required behavior | Observable assertion | Validation |
|---|---|---|---|
| A1 | Seed graph from the real fixture | 10 Session, 31 Turn, 31 Check, 5 Issue, 5 repaired Check nodes | `python -m unittest tests.test_memory_graph -v` |
| A2 | Session recall | `recall_session("Q1")` returns the Q1 title and 3 turns | same suite |
| A3 | Gate trace | `gate_trace("Q8")` returns 3 checks, 2 repaired, routing issue text | same suite |
| A4 | Scenario statistics | `scenario_stats()` includes `memory` with 4 turns and `routing` with 2 repairs | same suite |
| A5 | Constraint extraction | Q1 turn 1 yields at least 3 hard-constraint nodes | same suite |
| A6 | CLI works on a real `.rl` file | `seed` then `stats`, `ask`, `trace` all exit 0 and print expected rows | fresh commands |
| A7 | Public project surface | README, schema, evidence, demo script, license, notice | read + GitHub page |

## Constraints

- New work; not a re-upload of `xiaoyuan-14b-agent`.
- Relate store is a single `data/xiaoyuan_memory.rl` file, generated by `seed` and reproducible from JSON.
- All queries are parameterized; no string interpolation of user input.
- The demo is captioned and clearly local; no synthetic voice and no claim of official ranking.
- No private production source, no model weights, no personal data.

## Validation commands

```powershell
$py = ".venv\Scripts\python.exe"
& $py -m unittest discover -s tests -v
& $py -m xiaoyuan_memory_graph seed --reset
& $py -m xiaoyuan_memory_graph stats
& $py -m xiaoyuan_memory_graph ask "what did the agent remember from Q1?"
& $py -m xiaoyuan_memory_graph trace Q8-T1
```
